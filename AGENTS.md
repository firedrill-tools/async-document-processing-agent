# Working rules

Keep this a standalone, synthetic document-job application. Do not put provider keys or real documents in fixtures or tests. Keep Google ADK's invocation behind `ADKExtractor` so the job journal can be tested without a live provider.

Preserve job IDs, idempotency and fenced lease semantics across changes. A cancelled or superseded worker must not commit a result. Do not report a stub-model test as a live Gemini proof. Add Firedrill integration only against the verified new release, never the retired client.

`src/document_worker/__main__.py` is the CLI; `worker.py` owns processing/completion, `store.py` owns transactional state, and `agent.py` owns the ADK model call. `--db` selects a journal; independent cases use separate files. `fixtures/manifest.json` pins synthetic dataset version 1 and its four profiles; `scenarios/README.md` describes invocation, completion, reset, cancellation and observation-only exploration. The target receives only submitted document text.

Run `uv sync --locked --extra test && uv run --locked --extra test pytest -q` for the 26 offline checks. Worker claims, including recovery after expired leases, share a hard budget of three. A lease duration must be a positive integer. Preserve review status for missing fields, unknown types or reported concerns. Delete each ephemeral ADK session in `finally`, and close an owned extractor/runner after use. Journal data deliberately remains until its owner removes an inactive database and sidecars.

`DocumentExtraction` carries facts and ADK model observations separately from the model's output schema. Preserve requested/returned model identifiers and reported nonpartial usage events; unavailable usage and cost stay null. `ExtractionError` retains observations when available without claiming completed facts. `get` includes `job_attempts` history, while retry clears the current result and preserves the previous attempt's evidence. Cancellation can retain usage but must discard facts. Lease expiry means provider outcome unknown. A superseded worker's receipt must identify its own attempt and rejected commit; never attribute another worker's completion to it. A claim or usage event is not proof of a fresh completed model execution. CLI serialization must redact source and lease fields in both job and attempt records.
