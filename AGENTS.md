# Working on asynchronous document jobs

- Entry points: installed `document-worker`, `python -m document_worker`, `worker.DocumentWorker` and `agent.ADKExtractor`. Python 3.12+, `uv sync --locked --extra test`. `cases`, `init-case`, submit/get/list/cancel/retry are key-free. `work` requires an explicit GOOGLE_API_KEY and enabled GEMINI_MODEL/--model. No production business-tool fallback exists.
- Native Gemini uses ADK 2.12.0/google-genai 2.31.0/HTTPX 0.28.1, explicit Developer API endpoint/backend/key. `transport.py` public HTTP hooks preserve raw decoded bodies and reject non-STOP/blocked/multiple/malformed/unsupported content before SDK release. Native regression accepted MAX_TOKENS, SAFETY and absent finish. JSON generateContent is qualified; wire SSE is not.
- Native extraction owns a fresh model/runner, unique session and SDK/HTTP client per invocation. Delete sessions and close clients on success/failure/startup/cancellation/deadline. Google leaves injected HTTP clients open: explicitly close the application's owned client separately. Extractor close cancels active work, and one active document per extractor is enforced. Caller-supplied BaseLlm models/clients remain caller-owned; stub tests are separate.
- Budgets: one ADK model call, one SDK attempt, 4,096 output tokens/one candidate, 30-second HTTP phases and 120-second extraction/worker deadline. No automatic provider retry/repair. Local cancellation does not prove remote generation/billing stopped. CLI SIGINT/SIGTERM preserve available attempt observations and exit nonzero.
- DocumentFacts rejects unsafe/coerced integer cents and malformed dates/currencies/concerns. Missing issuer/currency/total, unknown type or concerns produces needs_review. Completion is an execution/state outcome, not field-accuracy assessment. Only document text enters the model; no external write/function tools exist.
- `store.py` owns SQLite transactions, exact delivery identities, fenced leases and a shared three-claim budget across explicit retry/expiry recovery. An expired token cannot commit even before replacement. Observe persists only to its original attempt/token, including late evidence; it never authorizes fact commitment. New DBs are private; existing journal permissions remain owner-managed. Connections close after each operation; no transaction spans model I/O.
- Worker results identify worker_attempt/worker_model_observation/commit_accepted separately from the job's current state, which may belong to a replacement. Cancelled/superseded facts are discarded while observations remain. A claim or usage event is not a fresh completed execution. A finalization error has unknown publication outcome: expose worker_receipt and inspect saved state, never automatically finalize again or undo a possible commit.
- Queued cancellation stops immediately; running journal cancellation is cooperative at commit. Caller/CLI cancellation leaves a running lease and durable interruption observations. Abrupt termination also recovers through expiry. Do not assume the simulation clock moves the application clock; JobStore(clock=...) is the explicit clock seam.
- `get` returns attempt history and observations; retry clears only the current failed result. Preserve original decoded body/status/request/model IDs, generation/input/body hashes, actual installed versions, raw reported counts versus SDK usage events, and missing/partial/invalid/reported-zero distinction. No inferred billing; cost stays null. Evidence cap is after buffering, not a wire/memory bound. Do not double-count raw and SDK measurements. Migration cannot fabricate old observations/ownership.
- `data/manifest.json` binds eight version-2 cases/four profiles. Busy: 17 jobs, twelve prior human completions, one human review, one cancellation, three queued. Human facts are human_import with zero claims/unknown usage. Seeded prior lease is fictional lifecycle history, not a model result. Legacy fixtures remain authoring inputs; regenerate with scripts/build_fixtures.py. Keep scenario/manifest expectations outside target context.
- Initialization validates hashes/identity and creates a new private DB exclusively. Wait for it to return before starting workers. Independent cases need separate DBs; stop owners before deleting a DB/WAL/SHM. Reset does not erase reports/provider billing/retention or caller resources. Metadata is declarative after edits; inspect actual document/request hashes. CLI must redact source text/content hash/lease tokens in jobs and attempts, while preserving model observations/results.
- Verification: `uv run --locked --extra test pytest -q`, `uv build`, `uv run --locked python scripts/check_distribution.py`. Wheel/sdist fresh locked installs verify actual CLI/data/worker/recovery outside checkout. CI also checks deterministic generation. Do not add a scripted production mode, guessed/retired Firedrill client or private platform source.
- Live Gemini quality/budget and visibility/license remain parked external gates. Keep standalone development progressing independently.
